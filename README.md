# Martin Groß · Webinar „Führung im Zeitalter von KI“

Landingpage für das kostenlose Online-Webinar am 25. und 26. November 2026.

- `index.html` ist die ganze Seite: eine Datei mit Inline-CSS, Google Fonts und drei Fotos in `images/`. Kein Build-Schritt.
- **FunnelSpot:** den Block `FUNNELSPOT-FORMULAR` durch das FunnelSpot-Formular ersetzen.
- **Vor dem Livegang:** `<meta name="robots" content="noindex">` im `<head>` entfernen.
- **Vorschau:** GitHub Pages dieses Repos, lokal `python3 -m http.server` in diesem Ordner.
